# WHAT IS MORSE CODE

Morse Code is a way to communication that shows letters, numbers, and symbols through short and long signals.

# HISTORICAL CONTEXT

Morse Code is one of the earliest systems used for a long-distance communication before telephones and the internet existed.Morse Code was developed in 1830s-1840s by Samuel Morse, an American inventor and artist, together with Alfred Vail.Thier goal was to send messeges quieckly over a long distance using electricity. Back then messages was sent using horses, ships, or messengers. Communication could take days or weeks. The invention of the electric telegram changed everything. Electrical signal were sent through wires, Operators used a key to tap signals and those signals formed Dots and Dashes. The first official telegraph messsge was sent in 1844 from Washingtin,D.C to Baltimore. The message was "What hath God wrought"

# HOW THE MORSE CODE SYTEM WORKS

Morse Code works by converting letters and numbers into pattens of dots and dashes that can be sent as a signals. Every character in morse code has its combination of dots and dashes. These signals can be sent by using Sounds(beep), light(flashing light), vibration and radio signal. The Dot(.) means long sighnal one unit and the Dash(-) means the long signal 3 units. Morse Code works by sending information using short and long signals(Dots and Dashes) seperated by specific time gaps to represent letters and words.
